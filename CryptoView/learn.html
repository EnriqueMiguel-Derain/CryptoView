FAQ

Is CryptoView giving financial advice?

No. It is an educational tool. Prices are for information only and the practice wallet uses virtual money.

Where does the price data come from?

Coinpaprika provides market data, Binance provides chart candles, and the fawazahmed0 exchange-api provides currency exchange rates. None of them need an API key.

Why do prices sometimes say outdated?

If a data source is slow or offline, CryptoView shows the last saved data with a notice until it can refresh.

Is my watchlist or wallet saved online?

No. Everything is saved in your own browser with localStorage, so clearing your browser data removes it.
